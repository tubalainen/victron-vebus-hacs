# Victron VE.Bus (MK3) 1.1.5

The Multi is the only source of its values. Home Assistant shows what the Multi
reports and keeps nothing of its own.

## Changed

- Setting numbers have an **Active value source** attribute: read from the Multi,
  a change the Multi acknowledged, or the stored value when the Multi can't report
  RAM. The **Stored value** attribute shows the EEPROM value whenever the Multi
  reports it.
- The **Configured AC input current limit** in effect is read from the Multi while it
  is below the remote limit, also after a restart of Home Assistant. Verified on a
  MultiPlus-II with firmware 556.
- The **Remote AC input current limit** number shows the limit the MK3 reports for the
  remote panel. It showed the limit in effect before, which is the *AC input current
  limit* sensor.
- **Save settings permanently** writes only values that differ from the stored ones. A
  change back to the stored value leaves nothing to save.
- The diagnostics download contains `readsetting_reports`.

See [RAM and EEPROM](https://github.com/tubalainen/victron-vebus-hacs/blob/main/docs/controls.md#ram-and-eeprom-the-multi-is-the-source).
