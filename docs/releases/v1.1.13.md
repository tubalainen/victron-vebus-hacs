# Victron VE.Bus (MK3) 1.1.13

New read-only sensors and a fix for two diagnostic sensors that were always unknown.
Nothing in this release writes to the Multi or restarts it.

## Added

- **Battery temperature** (°C), from RAM variable 21. It is created only if the Multi
  describes that variable, and it needs a temperature sensor connected to the Multi.
  Victron doesn't document the variable (VictronConnect names it "Battery
  temperature"), and the scaling comes from the Multi: please compare the value once
  with VictronConnect.
- **Ripple alarm** (ok, warning, alarm) and **VE.Bus error code** (diagnostic, 0 = no
  error), from the rest of the `L` reply that the integration ignored so far. They are
  decoded as VictronConnect does; Victron doesn't document the bytes, so there is no
  repair issue or event for them yet. They are only created if the MK3 sends the full
  reply. The diagnostics show the alarm byte (`alarm_flags`) and the status byte
  (`status_flags`, bit 7 = another tool holds the bus).

## Fixed

- **Relay** and **Ignore AC input** were always unknown on a Multi without a virtual
  switch, such as a MultiPlus-II with firmware 556. They were read in one request with
  the virtual switch, which such a Multi refuses as a whole. Now only the variables the
  Multi describes are requested.
