# Victron VE.Bus (MK3) 1.1.6

Fixes the remote and configured AC input current limits after a restart of Home
Assistant.

## Fixed

- **Remote AC input current limit showed 0 A** after a restart of Home Assistant. The
  Multi doesn't report this limit, only the MK3 does, and the MK3 forgets it when it is
  opened. The number is now *unknown* until a limit or mode is set. The Multi itself
  was never changed.
- **Configured AC input current limit showed the stored value** although the Multi ran
  with a higher RAM value. When the limit in effect is above the stored value, the
  number is now *unknown*. The attributes show the stored value and the lower bound
  (*Active value at least*), and the source *Unknown, at least the limit in effect*.
  Setting the remote limit once makes the value readable again.
- A **mode change** sent the limit in effect as the new remote limit, which could lower
  the remote limit. It now keeps the remote limit if it is known.

The diagnostics download contains `active_read` and `active_minimum`.

See [RAM and EEPROM](https://github.com/tubalainen/victron-vebus-hacs/blob/main/docs/controls.md#ram-and-eeprom-the-multi-is-the-source).
