# Victron VE.Bus (MK3) 1.1.10

## Fixed

- **Setting numbers missing after a start.** Sometimes the ranges of the settings
  weren't read completely when the integration started, and the numbers (charge
  current, absorption, float, configured AC input limit, solar & wind priority) didn't
  appear until the integration was reloaded. Every range is now read several times,
  and ranges that are still missing are read again every 5 minutes. The numbers
  appear as soon as their range is known, without a reload.

## Changed

- **Configured AC input current limit** is no longer derived from the limit in
  effect. On a MultiPlus-II the limit in effect wasn't always the lower of the remote
  and the configured limit, so the derived value could be wrong. The number shows
  the change the Multi acknowledged, or the stored value; the limit in effect is the
  *AC input current limit* sensor.

See [RAM and EEPROM](https://github.com/tubalainen/victron-vebus-hacs/blob/main/docs/controls.md#ram-and-eeprom-the-multi-is-the-source).
