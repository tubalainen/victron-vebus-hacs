# Victron VE.Bus (MK3) 1.1.2

A text-only release: the **Passthru** switch is now called **Stop grid charging (0 A)**.

"Passthru" looked as if it should be on in normal operation, all the more because the
*Device state* sensor shows Victron's normal grid-through state as *Passthru*. The
switch does something specific: it sets the remote AC input current limit to 0 A, so
the charger stops while the grid is still passed through to the AC outputs. Normal
operation (mode *On*) does not need it.

## Changed

- The switch, the guided dialog (*Configure → Device actions → Stop or resume charging
  from the grid*) and their warnings use the new name and explain what it does.
- [Controlling the Multi](https://github.com/tubalainen/victron-vebus-hacs/blob/main/docs/controls.md)
  explains when to use it.

## Upgrading

Nothing to do. Existing installs keep the entity ID `switch.victron_ve_bus_passthru`
(only the name shown changes); new installs get
`switch.victron_ve_bus_stop_grid_charging_0_a`. Actions and their fields are unchanged.
