# Victron VE.Bus (MK3) 1.1.9

> [!WARNING]
> **Fixes a bug present since 0.2.** Switching a feature **off** (PowerAssist, weak
> AC input, solar & wind priority) or the **UPS function on**, from a switch, the
> guided dialog or an action, also cleared bit 15 of the flag setting it changed.
> For setting 0 that bit is "Remote overrules AC2", which matters on devices with a
> second AC input (Quattro).

## Fixed

- Changing a flag now changes only that bit. Bits the Multi doesn't list as
  changeable are never touched; when the stored value is known they are taken from
  it.
- A RAM value with the cleared bit is repaired by the next flag change, and a restart
  of the Multi restores the stored value anyway.

## Check your settings if you used "Store permanently"

If you switched a feature off (or the UPS function on) with *Store permanently* in
1.1.8 or earlier, the stored setting may have lost bit 15. On a Quattro, check
*AC input 2 overruled by remote* (or the equivalent) in VEConfigure or
VictronConnect. A MultiPlus with one AC input is very likely unaffected in practice.

## Verified

Flag changes in RAM take effect at once, without a restart: PowerAssist switched off
on a MultiPlus-II removed the minimum input current limit and stopped the assist.
