# Victron VE.Bus (MK3) 1.1.7

Fixes from testing 1.1.6 on a MultiPlus-II.

## Fixed

- **Remote AC input current limit became unknown after a setting change.** Returning
  the MK3 to its normal mode after a setting write made it forget the remote panel
  state, and the same happened at start-up. The integration now sends the state back
  to the MK3, so the remote limit (and with it the configured limit in effect) stays
  known. As before, the Multi itself doesn't get this state.
- **A changed setting jumped back to the old value for a few seconds.** A poll that
  started before the change overwrote it when it finished. It now keeps the change.
- **Absorption voltage could be missing** (shown as unavailable) when its range wasn't
  read completely at start-up. The range is now read up to three times.

If the remote limit shows *unknown* after updating, set it once.
